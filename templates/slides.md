# Slide Deck Template

Use this template when the deliverable is a presentation (PowerPoint, Google Slides, or markdown slides).

## Core rule

**Every slide header is an insight, not a label.**

- Label (bad): "Market Analysis"
- Insight (good): "Mauritius's EV market will reach 1,200 units by 2026, driven by government import duty waivers"

The header should be the one thing the audience takes away if they read nothing else on the slide.

---

## Standard slide sequence

### 1. Title slide
```
[PROJECT TITLE]
[Company / Market / Decision]
[Your name] | [Course or Client] | [Date]
```

### 2. Agenda / Roadmap
```
[INSIGHT HEADER: e.g., "This analysis answers three questions"]
1. [Question 1]
2. [Question 2]
3. [Question 3]
Recommendation on slide [X]
```

### 3. Company / Situation Overview
```
[INSIGHT HEADER: one sentence capturing the key fact about the company]
• [Founding, HQ, revenue, employees — 2–3 specific facts]
• [Market position or competitive context]
• [Relevant recent event or strategic shift]
[Visual: company logo, map, or timeline]
[Source: company annual report / company website]
```

### 4. Problem Framing
```
[INSIGHT HEADER: the central question this project answers]
Situation: [what is true now — uncontested facts]
Complication: [what has changed or what challenge this creates]
Question: [the decision that follows from the complication]
[Visual: simple diagram showing the decision]
```

### 5–8. Analysis slides (repeat for each major finding)
```
[INSIGHT HEADER: the key finding from this section]
• [Supporting point with specific data] (Source, Year)
• [Supporting point with specific data] (Source, Year)
• [Supporting point with specific data] (Source, Year)
[Visual: chart, table, or framework diagram — describe what type]
[Source: citation]
So what: [one sentence on implication for the recommendation]
```

### 9. Recommendation
```
[INSIGHT HEADER: the recommendation stated directly]
We recommend [specific action] because [top 1–2 reasons].

Key supporting points:
• [Reason 1 with data]
• [Reason 2 with data]
• [Reason 3 with data]

[Visual: decision tree or comparison table]
```

### 10. Implementation / Next Steps
```
[INSIGHT HEADER: what needs to happen first]
| Action | Owner | Timeline | Success Metric |
|--------|-------|----------|----------------|
| ...    | ...   | ...      | ...            |
```

### 11. Risks and Mitigations
```
[INSIGHT HEADER: the biggest risk and how it's managed]
| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| ...  | H/M/L      | H/M/L  | ...        |
```

### 12. References
```
[All sources cited in full, formatted per course requirements]
```

## Writing standards for slides

- Active voice: "MG should enter via franchising" — not "entry via franchising is recommended"
- No hedge phrases: cut "it could be argued", "there are many factors", "it is important to note"
- Numbers are mandatory: "7% GDP growth" — not "strong growth"
- One idea per slide — if you need a second header, it's a second slide
- Bullets are parallel: all start with the same grammatical form
