# Written Report Template

Use this template when the deliverable is a written report or essay (typically academic assignments with a word count).

## Structure: Pyramid Principle throughout

Every section opens with its key finding — not a description of what the section covers. Build from conclusion to support, never the reverse.

---

## Section sequence

### Cover / Title Page
```
[Report title]
[Company / market / case]
[Author] | [Course code and name] | [Date]
[Word count] (if required)
```

### Executive Summary (10% of word count, max 1 page)

Answer the central question in the first sentence. Then:
- 2–3 sentences on the key supporting findings
- 1 sentence on the recommendation
- Do not include background or methodology here

Template:
```
[Company] should [recommendation] because [top reason].

[Key finding 1 with data]. [Key finding 2 with data]. [Key finding 3 with data].

This report recommends [specific action] by [timeframe], contingent on [key condition if any].
```

### 1. Introduction (5% of word count)

- Central question this report answers
- Scope: what is included and excluded
- Brief methodology: frameworks applied, source types used
- Road map: what each section covers

Do not include company background here unless the brief explicitly requires it.

### 2–4. Analysis sections (60–70% of word count)

Each section follows the same internal structure:

```
## [Section title — named for the question answered, not the framework used]

[Opening sentence: the key finding of this section, stated directly]

[Body: evidence organized by sub-point, each with data and citation]

[Closing sentence: implication for the recommendation — the "so what"]
```

One section per major branch of the issue tree. Typical sections:
- External environment (PESTEL, Porter's)
- Company position (VRIO, McKinsey 7S)
- Market analysis (STP, BCG)
- Mode or strategy recommendation (Ansoff, Modes of Entry, CAGE)

### 5. Recommendation (10% of word count)

State the recommendation in the first sentence. Then:
- Justify using the 2–3 strongest findings from the analysis
- Address the strongest counter-argument in one paragraph
- If multiple options were considered, state why the recommended option wins

Do not hedge: "Based on the analysis, it is recommended that..." → "MG should enter Mauritius via franchising because..."

### 6. Conclusion (5% of word count)

Restate the recommendation and the central question it answers. Do not introduce new information. One paragraph max.

### References

All sources cited in the required format (Harvard, APA, Chicago — confirm with brief). Every source cited in the body must appear here; no source appears here without being cited in the body.

---

## Writing standards

- **Active voice throughout**: "The analysis shows..." not "It can be seen that..."
- **Specific numbers**: cite the exact figure and its source
- **No filler openers**: cut "In today's globalized world...", "It is widely acknowledged...", "Since time immemorial..."
- **Section transitions**: end each section with its implication, begin the next with its key finding — the link should be logical, not "Furthermore..."
- **Citation placement**: immediately after the claim, not at the end of the paragraph
