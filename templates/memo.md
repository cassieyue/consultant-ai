# Business Memo Template

Use this template when the deliverable is a memo, business memo, or short-form written recommendation (typically 1–2 pages, often internal to a company or organization).

## Structure: SCQA

```
SITUATION   → What is true right now (uncontested facts)
COMPLICATION → What has changed or why the situation creates a problem
QUESTION    → What decision or action this raises
ANSWER      → Your recommendation, stated directly
```

The answer comes at the top, before the supporting analysis. This is the Pyramid Principle applied to memo format.

---

## Memo format

```
TO:      [Recipient name and title]
FROM:    [Your name and title]
DATE:    [Date]
RE:      [Subject line — state the recommendation, not the topic]
         Bad: "Mauritius Market Entry"
         Good: "Recommend franchising as preferred entry mode for Mauritius by Q3 2025"
```

---

## Body structure

### Opening (Situation + Complication + Answer — 1 paragraph)

```
[Company] currently [situation — key facts about the current state].
[Complication — what has changed or what challenge this creates].
This memo recommends [specific recommendation] because [top reason].
```

### Background (optional, 1 paragraph if needed)

Only include if the recipient needs context that isn't already known. Skip in most cases.

### Analysis (2–3 paragraphs)

Each paragraph = one supporting argument for the recommendation.

Paragraph structure:
```
[Topic sentence: the argument, stated as a conclusion]
[2–3 supporting facts with citations]
[So what: how this supports the recommendation]
```

Do not walk through frameworks step by step — extract the relevant finding and state its implication.

### Risks and mitigations (1 paragraph or short table)

Identify the 2–3 biggest risks to the recommendation and how each is managed.

```
| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
```

### Recommendation and next steps

Restate the recommendation in one sentence. Then list 3–5 concrete next steps:

```
We recommend [action] by [date]. Next steps:
1. [Action] — [owner] — [deadline]
2. [Action] — [owner] — [deadline]
3. [Action] — [owner] — [deadline]
```

### References (if academic or formal)

List all cited sources. Omit in informal internal memos where verbal citations are standard.

---

## Writing standards

- **Subject line is the recommendation** — not a topic label
- **Answer before analysis** — never build up to the conclusion
- **One idea per paragraph** — if a paragraph makes two arguments, split it
- **Cut hedge language**: "it may be worth considering" → state the recommendation
- **Specific numbers**: "USD 2.3M investment" not "significant investment"
- **Bullet points only for lists** — not as a substitute for coherent paragraphs
- **Total length**: 1–2 pages unless specified otherwise
